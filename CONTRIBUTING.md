# Contributing

Contributions are welcome.

1. Do not include real alarm data, customer identifiers, production addresses,
   credentials, packet captures, vendor binaries, or copyrighted manuals.
2. Create a focused branch and keep changes small.
3. Build the solution and run both executable test projects.
4. Explain behavioural and configuration changes in the pull request.

By contributing, you agree that your contribution is licensed under the MIT
License used by this repository.
